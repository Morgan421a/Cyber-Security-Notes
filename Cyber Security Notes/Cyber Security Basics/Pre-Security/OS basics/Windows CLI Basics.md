**Basic Commands**
- `cd` - Used to show path to current location as well a changing directory

- `dir` - Lists files and folders present in current directory
	- `dir /a` - Used to find hidden directories
	- `dir /s` - Search all sub folders starting from current directory and show file path if file exists

- `type <filename>` - prints contents of file directly in command prompt (windows' terminal)

- `whoami` - prints username of current user/account

- `hostname` - prints name of computer <- helps identify network systems in workplaces

- `systeminfo` - prints OS information
	- OS Name, OS Version, System Type <- Indicate which version of Windows the machine is running and whether it's 32-bit or 64-bit

- `ipconfig` - Shows network configuration, including IP addresses, default gateways, etc.
