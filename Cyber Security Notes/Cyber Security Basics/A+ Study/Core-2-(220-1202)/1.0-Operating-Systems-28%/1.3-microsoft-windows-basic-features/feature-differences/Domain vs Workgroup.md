### Domain
- Active Directory Domain Services Database
	- Large database of a org's network
	- Contains information about every component connected to the network
		- Includes Usernames, User Permissions, Security Feature Info, etc.
- Everything is documented in one centralised place
	- Allows for easy central management of an org
	- User Accounts, servers, volumes, printers, etc. are all able to be managed through the Domain
- Active Directory (AD) = A **Distributed Database** <- Can have multiple versions of the AD database located in different parts of the network
	- Useful for scalability and orgs with many devices such as servers
	- Not suitable for home use
- Has many different uses, such as Authentication, Centralised management, etc.

### Workgroup
- Workgroup = **A logical group of network devices**
- Each device is a single unit and is managed as such
	- Everyone is a peer
- More appropriate for home networks
