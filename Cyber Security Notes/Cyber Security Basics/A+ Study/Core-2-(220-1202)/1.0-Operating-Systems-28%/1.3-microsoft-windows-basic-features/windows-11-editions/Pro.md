- Designed for business or large orgs
	- Allows for large scale system management
- Integrates with Active Directory to allow for systems management from a central location
	- Active Directory (AD) = Microsoft's Directory Services
- **Includes FDE through** Microsoft's **BitLocker** functionality
- Offers **virtualisation** **through** **Microsoft Hyper-V**

#### Windows 11 Pro Edition Feature Breakdown
- Access to Windows Domains
- Includes BitLocker Support
- Can use Remote Desktop as a Client and Host/Server
- Offers Group Policy Management
- **64-bit (x64) version**:
	- Supports **up to 2 TB RAM**
	- **Minimum Processor** = **1 GHz** minimum **clock speed**, at least **two or more cores**
- **No Support for 32-bit (x86) systems**

#### Licensing Options:
- **OEM** (Original Equipment Manufacturer)
- **Retail License**
- **Volume Licensing**:
	- Used by businesses that have multiple devices
	- Single activation key for multiple installations
	- Saves costs for orgs buying 10 or more licenses
