### Third-Party Drivers
- May be necessary to install alternate, third party drivers when installation program may not recognise all of the hardware in a computer
	- Example:
		- Hardware RAID controllers may need specific drivers for proper detection
		- Network adapter drivers may be required to ensure connectivity after installation
		- Ensure all the needed drivers are available and can be installed during the upgrade process
- May be prompted during OS installation to install Third Party Drivers
	- Prompt typically only appears for hardware drivers needed for OS installation
