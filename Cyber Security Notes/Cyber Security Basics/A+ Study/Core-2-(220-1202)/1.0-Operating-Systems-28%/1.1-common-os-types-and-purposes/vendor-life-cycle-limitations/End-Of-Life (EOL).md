- Different companies have different standards for EOL
	- e.g. Apple EOL requirements differ from EOL requirements for Microsoft Products
#### Windows
- **Server** OS's typically **supported** for **~10 years**
- **Desktop** OS's typically **supported** for **~5 years**
#### Linux
- **Standard Release Model**:
	- Users version numbers for updates, e.g. Ubuntu 22.04.1 LTS
	- **Long-Term Support (LTS) versions** receive updates for **5 years**
	- **Non-LTS versions** receive updates for only **9 months**
- **Rolling Release Model**:
	- Doesn't use version numbers
	- Updates released continuously <- Ensures latest features and security patches are always installed
	- Arch Linux is a popular rolling release distribution
#### Android
- **Average support period** = **3 Years**
- Upgrades limited by device hardware
- Backwards support usually lasts 3-5 years
- Security risks if updates no longer available for older devices
#### Apple
- Provides free updates for the lifetime of a device
- **Devices** **supported** **for** an **extended period**, **typically 6+ years**
- Older devices eventually unsupported by updates
