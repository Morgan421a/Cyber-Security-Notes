- Apple's OS designed for use on their iPhones
	- Based on Unix
- Closed-source <- No access to source code
- Operates exclusively on apple hardware
#### iOS Apps
- Apps designed for use on iOS, macOS, or iPad OS must be developed using **Apple's SDK** (Software Developer Kit) which runs on the macOS operating system
- **Apps** must be **tested and approved by Apple prior to release**
- Apps are available to users in the **Apple App Store**
