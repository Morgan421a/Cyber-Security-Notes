### RJ-11
- **RJ-11 = Registered Jack Type 11**
- **6 Position, 2 Conductor (6P2C)**
	- Some cables need additional conductors
- **Typically** used for **Telephone or DSL connection**
- Slightly taller and thinner than an RJ-45 connector

## RJ-45
- **RJ-45 = Registered Jack Type 45**
- **8 Position, 8 Conductor (8P8C)**
- Sometimes referred to as:
	- Ethernet Connector
	- Modular Connector

### F-Connector
- **Threaded connector** used for **Coax Cable**
- Commonly used for **Cable television** connections
	- Extends to **cable modem** <- Uses DOCSIS

### Punch-down Block
- Wire-to-wire patch panel, no intermediate interface required
- Wires "punched" into the block <- Connecting block is on top

### USB Connectors
- **USB 1.1/2.0**:
	- Standard-A Plug <- "Normal" USB plug
	- Standard-B Plug <- More square, commonly used for peripherals
	- Mini-B Plug <- Shaped almost like a squashed loaf of bread
	- Micro-B Plug <- Square arch type shape
- **USB 3.0**:
	- USB 3.0 Standard-A Plug <- Almost identical to "Normal" USB Plug
	- USB 3.0 Standard-B Plug <- Slightly taller than 1.1/2.0 Standard-B Plug
	- USB 3.0 Micro-B Plug <- Long bit, flat bit, short bit design from left to right
- **USB-C**:
	- **24-pin double-sided USB connector**
		- Double sided = can be **inserted either way** around
	- Used for both **hosts and devices**
	- Used for USB, Thunderbolt, HDMI, etc.
		- **Interface** is the **same**, **signal** can **vary**

### Molex Connector
- **4-pin peripheral power connector**
- Sometimes referred to as an **AMP Mate-n-Lok**
- Often provides **+12 V** and **+5 V Power**
- Used to power many devices in a computer case such as fans, storage devices, and other peripherals <- Commonly seen in **older computers**

### Lightning
- **Apple Proprietary**
- **8-Pin, digital signals**
- Used only for Apple products, specifically older models <- Current models tend to use USB-C
	- iPhone, iPad, iPod, etc. 
- Has **some advantages over Micro-USB**, including:
	- **Higher power output** for phones and tablets
	- Can be **inserted either way**

### DB-9
- D-Subminiature / D-sub
	- Letter refers to connector size
- **Commonly** used **for** **RS-232**
	- RS-232 = Recommended Standard 232
- Used as the **standard for** **serial communication** before USB
	- Built for **modem communication**
	- Used for modems, printers, mice, networking
- Still used since a lot of modems, routers, and other infrastructure devices that use DB-9 as a **configuration port** (management or console port)
