### Expansion Cards
- **Extend** the **Functionality of** a **computer**, beyond what the motherboard provides
	- Extended functionality can be in the form of **functions or ports**
- After installation, **OS may automatically identify** the **card** **and** **install** the **device drivers** for it
	- May need to be done manually
	- **Driver** = Software for the operating system

### Sound Card
- **Provides Audio Output** even if the motherboard already does
- Support advanced configs such as 5.1 or 7.1 surround sound
- **Offer high-end audio**, typically **superior to** what the **motherboard** offers
- Tend to offer advanced headphone amps
- Can have **additional output functions** **to** **plug devices into** such as a home theatre with multiple speakers
- Tend to **provide multiple inputs** **for devices** such as microphones **to be plugged in**

### Video Card
- **Many CPUs include** an **integrated GPU**
	- Video functionality built into the CPU package
- **Discrete Graphics Adaptor**
	- **GPU** that's **external to** the **CPU**
- **Separate interface card** provides **higher performance**
- Has own **video output on** the **rear of** the **card** itself
	- Ports such as Thunderbolt, DisplayPort, HDMI, etc.
- Allows **graphical processing** to be **offloaded to the GPU**
- **High speed memory embedded in** the **card**
- Installed in PCIe x16 slots on the motherboard

### Capture Card
- Allows for **video** to be captured **as an Input** e.g. video capture, live streaming, external cameras
	- **Move video data into the computer for processing**
- Typically offer **high performance**
	- **Video bandwidths** can be **quite high**
	- Often use the **PCI Express** (PCIe) **connection**

### Network Interface Card (NIC)
- Allow for **connection** **to** a **network** **via Ethernet** **or Wireless** connections
	- Motherboard may not include an NIC or it may not be working
	- **Can** also **be installed when using devices that require multiple ethernet connections**, such as servers, routers, or security devices
- Some cards support multiple Ethernet connections <- Called **Multi-port Ethernet** cards

### Documentation
- Check **motherboard documentation** **to** **ensure** it has the **correct number and type of interfaces**
- Check **adaptor card documentation**
	- **Find** out what the **minimum hardware and software requirements** are to use the particular hardware
	- Check **manufacturer knowledge base** to see if any other requirements or known issues with the device have been unaccounted for in initial documentation search
	- Check **Support forums** to see what other users have said or found about a piece of hardware
- **Some** adaptor **cards** **need** the **driver installation before installing** the **hardware**
	- **Others need** the **driver installation after** the **hardware** is **installed**

### Driver Installation
- Check web for **latest version**
- **Uninstall previous drivers** through **Windows Device Manager**
- **Installation done** either **through Windows front-end or** a **Manufacturer provided setup** **program**
- **Driver installation and status check** post install can be **done through Windows Device Manager**
