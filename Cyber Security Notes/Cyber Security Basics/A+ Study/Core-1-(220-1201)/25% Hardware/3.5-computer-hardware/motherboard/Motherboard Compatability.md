### Intel and AMD
- Two major CPU manufacturers
	- Subtle differences
- AMD tends to be a bit less expensive
	- Often makes CPUs that are compatible with Intel
- **Different CPU Sockets on motherboards**
	- Motherboards designed for a particular CPU
	- **CPU Sockets use** a **ZIF** (Zero Insertion Force) **mechanism**
		- Ensures CPUs can be installed without force <- Reduces risk of bending pins
- Historically, AMD is value, Intel is Performance
	- Switch places often
#### Socket Types
- **LGA** (Land Grid Array):
	- Manufactured by **Intel**
	- **Pins on** the **motherboard**, **CPU** **has** corresponding **contact points**
- **PGA** (Pin Grid Array):
	- Manufactured by **AMD**
	- **Pins on CPU**, **motherboard has** corresponding **contact points**

### Server Motherboards
- **Tend to need more processing power**
	- As such are **often** **multisocket** <- allows **multiple CPUs with matching sockets** to be installed which **splits the load**
- Server motherboards often support **multiple memory module and expansion slots**
	- **Typically 4 or more memory slots** 
	- Often have **different sizes of expansion slots** to allow for purposeful component usage
- Typically **designed** **to fit** into a **19" rack-mounted system**
	- Tend to use **full sized ATX motherboard**

### Soldered Processors
- Commonly found in **mobile devices** (laptops, smartphones, tablets)
- **CPU soldered directly to** the **motherboard** <- **cannot be removed or upgraded**
- Typically use **Intel**, **AMD**, or **ARM-based chips**
