### Memory
- Typically used in reference to **RAM (Random Access Memory)**
	- Most common, but isn't the only type of memory
	- RAM = Temporary, high-speed Data storage, used by apps and process when executing apps or performing calculations
		- Apps and data from storage drive often loaded into the RAM when and app is used

### RAM (Random Access Memory) Slots
- Memory types have changed over the years, driven by standardisation and improvements to technology
- Memory often considered one of the most important components of a computer
	- Memory speed typically associated with overall performance of a computer <- faster memory often means a faster computer
- Every motherboard is different, some may not be compatible with certain memory types
	- Check mobo documentation before changing memory
- **RAM modules** are **keyed** to **prevent incorrect installation**
- **Some motherboards** allow for **mixed sizes** (e.g. 4GB + 8GB = 12GB), others don't
- Recommended to use identical modules in pairs for optimal performance
- **Mixing speeds** causes **faster module** to **run at** the **slower module's speed**
	- Speed measured in megabytes per second (e.g. PC4-16000 = 16,000 MB/s or 16 GB/s)

### DIMM - Dual Inline Memory Module
- **Dual** because **electrical contacts on both sides**, but **different** on **either side**
- **Data written/read from memory** done in 64-bit blocks <- called **64-bit data width**
- Install Modules at 90 degree angle, secure with the retaining clips

### SO-DIMM - Small Outline Dual In-line Memory Module
- Typically used in laptops and other mobile devices
- About **half the width of a standard DIMM**
- Tend to be installed horizontally in laptops as opposed to vertically
- Insert at 45 degree angle, push down flat to lock

### Dynamic Random Access Memory
 - The **memory on the DIMM**
 - **Dynamic** = Needs **constant refreshing**
	 - Without refreshing, data in memory disappears
- **Random Access** = Any storage location can be accessed directly at any time, unlike magnetic tape 
	- **Magnetic Tape**: 
		- Older storage method
		- Requires fast forwarding and rewinding to access specific data 
		- Still used in modern data centres and cloud storage due to "air gap" that protects data from ransomware and cyber threats

### SDRAM - Synchronous Dynamic Random Access Memory
- RAM type typically used in computers
- **Synchronised** to a **common internal clock on** the **computer**
	- Keeps **data moving at a standard rate**, queues up one process while waiting for another
	- Classic DRAM didn't wait for a clock signal

### SDR (Single Data Rate) vs DDR (Double Data Rate)
- **SDR**: 
	- Used by older styles of memory
	- **One clock cycle** = **one piece of data** being **transferred** from memory to CPU and back
- **DDR**:
	- Used by modern styles of memory
	- **One clock cycle** = **two pieces of data** being **transferred**, **one at the top** and **one at the bottom of** the **clock cycle**

### Memory Generations
- **Sequential advancements in speed** (DDR, DDR2, DDR3, DDR4, DDR5)
	- Due to larger chip capacities
- Generations **not backwards compatible**
#### DDR
- 184 pins
- Example:
	- PC-1600 (1.6 GB/s throughput)
#### DDR2
- 240 pins
- Example:
	- PC2-4200 (4.2 GB/s throughput)
#### DDR3
 - 240 Pins
 - Example:
	 - PC3-10600 (10.6 GB/s throughput)
- **Max size = 8 GB per module**
#### DDR4
- 288 Pins
- Example:
	- PC4-16000 (16 GB/s throughput)
- **Max size = 32 GB per module**
#### DDR5
- 288 Pins
- Example:
	- PC5-42000 (42 GB/s throughput)
- **Max Size = 128 GB per module**
