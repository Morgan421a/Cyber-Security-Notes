### Pixel Density
- **Measures** how many **pixels per inch** (PPI) (or per centimetre)
	- Allows for displays to have a physical measurement applied to them
- **Higher pixel density = Higher quality image** <- better clarity and sharpness
- The way in which an image will be viewed should be considered:
	- Always looked at on a screen
	- Will it be printed? <- If so printer specs should be checked to see if the printer's **Dots Per Inch (DPI)** can properly present the image on the screen
		- **PPI = Display**, **DPI = Print/Scan**
- 1 PPI = 1 pixel in a 1 square inch area (horizontally and vertically):
	![[Pasted image 20260830083025.png]]
	- 8 PPI = 8 pixels across and 8 pixels down in a 1 square inch area
- Higher density better for photo editing, gaming, reading fine text
- **Increased processing power** **demand** and may have an **impact on battery life**
#### Pixel Density Comparison
- PPI = Number of pixels / Number of inches/centimetres
	- e.g. 27 inch (diagonal) 4K display:
		- 3,840 horizontal pixels / 24 inches wide (not diagonal) = 160 Pixels per Inch (PPI)
	- 65 inch (diagonal) 4K television:
		- 3,840 horizontal pixels / 57 inches wide = 67 PPI <- image same resolution as smaller display but PPI is different due to same number of pixels being spread over a larger area

### Refresh Rates
- Images are not static, they're constantly refreshed on a display every second
- **Refresh rate measured in hertz (Hz)**
	- Number of cycles per second
	- Also referred to as **Frames Per Second (FPS)**
- Some displays can be configured such that the **hertz equals the fps** to keep them synchronised <- Called **Vertical Sync (Vsync)**
	- Some display configs may only update a portion of the display on each cycle per second
- Frame rates may vary:
	- Movies: 24 fps
	- Television: 30 fps
	- Video Games: 60 fps and higher
- **Higher refresh rates** better **for** **rapidly moving content**, e.g. gaming, sporting events, video production, etc.
- **Max refresh rate determined by** both the **video adapter/processor** **and** the **display device**
	- **Connection type** **between** the **video card/video subsystem** and **display device** is also important:
		- **HDMI 2.1** supports 4K at 144 Hz
		- **DisplayPort 2.1** supports **dual** 4K at 144 Hz
- **Higher refresh rates demand more processing power**
- Common refresh rates:
	- 60 Hz <- Standard for general tasks such as web browsing and document editing
	- 120 Hz - 144 Hz <- Ideal for gaming and high-speed video playback, reducing motion blur
	- 240 Hz <- Used for competitive gaming with the smoothest motion

### Screen Resolution
- The number of pixels displayed horizontally and vertically on the screen
	- Width x Height
- More pixels = More detailed display output
	- Better perceived sharpness and a clearer view
- Many standards for different resolutions:
	- Can vary widely
	- **16:9 aspect ratio** is common
- Examples:
	- 720p = 1280 x 720
	- HD/1080p = 1920 x 1080 <- Standard for most screens
	- 1440p = 2560 x 1440
	- 4K = 3840 x 2160 <- Higher detail and clarity, preferred for video editing and HD content
	- 8K = 7680 x 4320 <- Ultra-high resolution for professional and cinematic use
- **High resolution = more detail** but **require more processing power**
- Optimal Resolution depends on screen size:
	- 15" laptop with 1080p resolution appears sharp
	- 65" monitor with 1080p resolution may look pixelated

### Colour Gamut
- The **range of colours available** on a display or output device
	- **Less than the capabilities of the human eye**
	- Wider colour gamut = more vibrant and accurate colours
- Important to consider when choosing a display:
	- Different colour representations and range of colours between displays
- **CIE 1931 Colour Space** used to **measure** the **colour gamut** of displays
	- Background colour image = colour image viewable by the human eye
- Different standards applied to displays using the **CIE 1931 Colour Space**:
	- **ProPhoto RGB** <- No displays fully use due to larger range of colours visible to human eye; used by photographers to prevent colour clipping during editing but not for displaying images (images converted to smaller space for final output)
	- **Adobe RGB** and **DCI-P3** <- Broader range of colours for professional applications
	- **sRGB** - Standard Red Green Blue <- Standard for general use
	- **SWOP CMYK**
	- **International Telecommunication Union (ITU)** standards for HDTV
	- **High Dynamic Range (HDR)** <- Enhances brightness, contrast, and colour to create lifelike images
		- Ideal for photography, video production, and graphic design

### Colour Coverage
- A display may be compared with an existing colour gamut standard
	- Part of the display specifications
- Gamut compatibility can vary widely
	- Higher percentages tend to be more expensive
- **OLED** displays provide a wide colour gamut
	- Best-in-class colour gamut support
