### Inkjet (ink-dispersion/high-dispersion) Printer
- Able to produce **high resolution output**
- **Quiet** operation
- **Relatively inexpensive** technology
- **Ink Expensive** 
	- Often **proprietary** to printer manufacturer
- **Ink** tends to **fade** **overtime**
- Type of **Ink** used **clogs easily**
- **Print line-by-line** instead of the whole page, unlike laser printers
- **Unidirectional print method** <- **Prints** only **when moving in one direction** (left to right); **slower** but **higher print quality**
- **Bi-directional print method** <- **Prints** **in both directions**; **faster** but **may reduce print quality** slightly

### Ink Cartridge
- **Drops of ink pulled from** a set of **cartridges** **and placed onto** a **page**
- **Cartridges** tend to have **4 colours**:
	- **CMYK** -> **Cyan, Magenta, Yellow, Key (Black)**

### Print Head
- **Some** consumer **printers** **integrate print head into ink cartridge**
	- **Changing** the **cartridge** **means** getting a **new print head**
	- **Integrated print head = Thermal Print head**
	- **Separate print head = Piezoelectric print head**
- **Have nozzles to spray ink droplets onto paper, moving back and forth across the page**
- **Other models** may **keep ink cartridge** **and** **print head separate**

### Feed Rollers
- **Pick up and pull paper through** the **printer**
	- **Must be cleaned and not worn**
- **Duplexing**
	- Print on both sides of paper
	- Included with some printers not all
