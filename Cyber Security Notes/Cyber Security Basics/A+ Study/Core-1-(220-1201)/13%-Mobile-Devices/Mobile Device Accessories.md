### Stylus
- Digital Stylus = more advanced writing tool, granting users more precision when interacting with touch screens, usually having various features such as:
	- Modern stylus typically come with pressure sensitivity
	- Some have programmable buttons
- The Stylus Communicates Directly to the device
- Stylus needs to be compatible with connected device for it to work
	- e.g. Apple laptop needs the Apple Pencil

### Headsets
- Hands-free audio
	- Typically consist of both earphone and a microphone
- Wired headsets:
	- Most modern devices often use **USB** connections
	- Some older devices tend to use an analog connection via a **3.5 mm TRRS (tip-ring-ring-sleeve) connector**
		- Tip = connection closest to device it plugs into
		- Rings = Two connectors that sit between the Tip and Sleeve, usually carrying left audio and right audio, and the ground/mic split across TRRS
		- Sleeve = Connector closest to the sleeve of the peripheral device itself
		- Sometimes called an **analog audio jack**
	- Older iPhone models can use the lightning port instead of USB
- Wireless headsets:
	- Typically connect via Bluetooth
	- Battery powered
	- Often use no wires

### Speakers
- Provide mobile audio
	- Battery powered
	- Typically provide better sound quality/fidelity than native mobile device speakers
- Usually connected wirelessly via Bluetooth

### Camera/Webcam
- Usually external on desktops and some laptops
	- External cameras typically connect via a USB connection
- Typically Internal on laptops/tablets/phones
- Usually accessible from multimedia apps, photo utilities, and video conferencing
- Allows for real-time video communication

### Docking Station
- Quick and easy way to connect and disconnect a mobile device (often a laptop) to multiple peripherals, monitors, and power sources through a single connection
	- Typically connect via USB-C or Thunderbolt
- Removes need to plug in multiple individual cables
- Often provide additional interface options and functionality
- Some docking stations allow for full size interface cards to be plugged into them
##### **Port Replicator**
- Similar to docking station but usually connect via a USB connection meaning they're usable for most devices such as laptops or even desktop computers
- More portable than full docking stations due to smaller size
- Does not commonly have an expansion card option
- Useful where support for additional adaptor cards aren't needed

### Trackpad
- Replaces external mouse as a way to control the mouse on a computer
	- Useful in tight work areas since less space is needed
	- Commonly found built-in to laptops
- External Versions exist:
	- Often Bluetooth connected and battery powered
	- Can be used for desktops
- Tend to have features that a standard peripheral mouse is incapable of, such as:
	- Drag and tap
	- Multiple finger input for:
		- Right-Clicking
		- Zooming
		- Window control
- Most laptops allow the trackpad to be disabled via the use of a function key (e.g. `F7`)
##### Drawing Pad
- Uses an active stylus with an external digitiser
	- Allows for very precise input
- Typically a third-party external device
	- Being third-party often means they're supported across many different Operating Systems
	- Usually connects via Bluetooth or a USB connection
