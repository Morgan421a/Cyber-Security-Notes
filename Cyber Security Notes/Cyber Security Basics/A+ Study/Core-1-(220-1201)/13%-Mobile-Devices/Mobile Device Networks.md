### Cellular Networks
- Work by using antennas which separate areas into **"cells"**
	- Antennas allow coverage within a cell using different frequencies which all together form a cellular network
- Enable voice and data communication
	- Mobile Device users can decide how the information is used by their device
		- e.g. turning of cellular data functionality to allow for only voice communication
		- Airplane mode disables all cellular networks on a device
### 3G Technology
- Introduced in 1998
- Allowed for larger amounts of data to be sent and received over cellular networks
	- Incremental 3G updates improved speeds
	- Usually several megabits per second
- Bandwidth improvement boosted the capabilities of mobile devices and added new functionality such as:
	- GPS
	- Mobile TV
	- Video on Demand
	- Video Conferencing

### 4G and LTE
- **Long Term Evolution (LTE)**:
	- A 4G technology
- Based on **Global System for Mobile Communications (GSM)** and **Enhanced Data Rates for GSM Evolution (EDGE)**
- Allowed for bandwidths up to 150 Mbit/s (megabits per second)
- Eventually upgraded to **LTE Advanced (LTE-A)**
	- Allowed for bandwidths up to 300 Mbit/s

### 5G
- Fifth Generation Cellular Networking
	- Launched globally in 2020
- Boasted significant performance improvements:
	- Uses higher frequencies across two primary ranges:
		- Frequency Range 1 (FR1) = 410 MHz to 7.125 GHz (Sub-6 GHz)
			- Wide coverage (several Kilometres)
			- Strong penetration through walls and buildings
			- Speeds tend to range from 100 Mbit/s to 700 Mbit/s
			- Ideal for rural and suburban areas
		- Frequency Range 2 (FR2) = 24.25 GHz to 71 GHz (millimetre wave (mmWave))
			- Very short range (often under 1 kilometre)
			- weak penetration, easily blocked by buildings, trees, even rain
			- Extremely high capacity and ultra-low latency
			- Speeds tend to range from 1 Gbit/s to 10+ Gbit/s
				- Offers fastest possible 5G experience
			- Ideal for dense urban hotspots, stadiums, and fixed wireless access where line-of-site is available and massive data throughput it required
- Significant Internet of Things (IoT) impact:
	- Bandwidth is less of a constraint
		- Allows for large amounts of data to be transferred
			- Which allows for faster monitoring and notification
				- Which allows for more data to be sent to the cloud for processing

### Wi-Fi
- 802.11 Wireless has also seen significant increases in speed and function
	- High speed 802.11 networks commonly used in households and offices
	- Improvements allow for high speed data throughput without the need for a wired connection
	- Removes the constant need to use cellular bandwidth
- Limited range 
- Requires a local access point for everyone to connect to in order to gain access to the 802.11 network
- Wi-Fi functionality enables voice, video, data, and almost any other type of data transfer
- 802.11 network provides functionality for many different types of apps
- Most phones allow for voice communication over the 802.11 network (Wi-Fi Calling)
	- Requires support from the voice carrier
	- Useful when cellular coverage may be unavailable
##### Hotspot
- **Hotspot** = Turning phone into an internet router, allowing multiple other devices to use the phone to gain internet access
- Hotspot device connects to cellular network via 5G, other devices connect to the phone over 802.11
- Must be enabled by provider
	- May also incur extra charges and data cost

### Subscriber Identity Module (SIM)
- Sometimes a physical card inside the phone
- Contains information that identifies what the phone is on its mobile network, both for the carrier and user, some of the information includes:
	- The SIM ID and phone number
	- Cellular network information
	- Storage Space for contacts, messages, etc.
- Replacing SIM changes the phone number
- Newer phones tend to use an eSIM  (Embedded SIM)
	- SIM resides inside the device and cannot be physically removed
	- SIM can be moved on the device through the use of software on the phone (i.e. Add or remove eSIM)
- Many devices support multiple SIMs

### Bluetooth Pairing
- Pairing process ensures security
	- Usually through the use of a Personal Identification Number (PIN) during the initial pairing process
- Devices usually only need to be paired once via full PIN process
	- Future connections with the same device should be automatic
- Process may be different between devices, as such manufacturer's guide should be checked
##### Bluetooth Pairing Process
1. Enable bluetooth on both devices
	- Typically done in the *Bluetooth* section of the *Settings* app on iOS and Android
2. Set both devices to discoverable mode
	- Might require a key sequence on the Bluetooth device (usually instructed in manufacturer's guide)
3. Select discovered device
4. Enter or Confirm PIN if asked
	- Should be the same on both devices
	- Could be embedded into the Bluetooth device or dynamic such that it changes every time it attempts the pairing process (manufacturer's guide usually states where to find the PIN)
5. Test Connectivity
	- e.g. Turn off one of the devices and see if they automatically re-connect upon turning it back on

### Global Positioning System (GPS)
- Created by U.S. Department of Defense (DoD)
- Uses satellites in orbit (Currently over 30)
- Requires at least 4 satellites to be visible to device at once for accurate GPS readings
- Determines location based on differences in the signal received by each satellite to determine longitude, latitude, and altitude above sea level
- Other ways of tracking location include:
	- Apps using Wi-Fi networks around a device to determine their location, even if GPS is unavailable
	- Some cellular networks can triangulate position based on the different cellular towers nearby
	- Geo-tracking: Uses a mix of Wi-Fi, cellular tower triangulation, Bluetooth beacons, and GPS to pinpoint exact coordinates
