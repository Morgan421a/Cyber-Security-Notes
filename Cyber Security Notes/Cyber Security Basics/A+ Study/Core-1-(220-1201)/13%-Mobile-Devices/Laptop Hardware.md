### Batteries:
- Some batteries are modular, easy to remove and replaced	
- Some are built into the laptop and designed not to be swapped out by the user	
- Most common types are:
	- Lithium-Ion (Li-ion)
	- Lithium-Ion Polymer (LiPo)
	 -Neither type has the "memory affect", meaning charging them does not diminish their capacity

### Laptop Keyboard:
- Typically easy to replace, only a few screws and a single ribbon cable, but it's not always the case
- External USB cable can be used to troubleshoot issues with the keyboard i.e. whether the issue is the laptop keyboard itself or the OS
##### Laptop Keys
- Some repairs may require the removal or replacement of a key cap
	- Can be a delicate procedure and manufacturer's instructions should be followed to ensure keys and keyboard aren't damaged in the process

### Laptop Memory
- Use **Small Outline Dual In-Line Memory Module (SO-DIMM)**
- Memory used in laptops and mobile devices are often easy to install and replace
- Some laptop memory is soldered to system board
	- Meaning no option to upgrade the memory is available without replacing the entire system board

##### Laptop Storage
- Old models used a **Magnetic Disk**
	- Similar, smaller variation of a HDD which used spinning drive platters
	- 2.5" form factors (3.5" used for desktops)
- Modern Laptop Models use **SSD (Solid-state drive)**
	- No moving parts, just memory, more reliable
	- Silent, Fast access time, lower latency
	- 2.5" form factors
	- 2 connections, one for power and one for data
- Newer laptops tend to use an **M.2 drive**
	- Smaller form factor
	- No SATA data or power cables
	- Easy to install and replace
	- One connection for data and power

##### Replacing Laptop Storage
- Some laptops, storage replacement is easy:
	1. Open a cover on the back
	2. Open the entire laptop
	3. Remove old drive
		- SSD, tend to have two screws and the drive slides out
		- M.2 drives, tend to have one screw and slide out
	4. Install the new drive
		- SSD, Slide into SSD slot, screw in new drive
		- M.2, Find the M.2 Slot, slide the copper connectors into the slot until none are showing, screw drive to the board
	5. Replace back

##### Migrating from HDD to SSD
- Imaging/Cloning software can be used to duplicate data from the old HDD to the new SSD
	- Helps cut down the time it takes to move data from the old drive to the new one
	- Removes the need to install an OS on the new drive
	- Some manufacturers include imaging software with the SSD, otherwise third party software can be used
	- Sometimes an image file of the system will need to be created, stored on another storage device, then install the new drive, finally copy everything from the image file to the new drive
		- Possible to copy an image from the old drive straight to the new drive if both old and new drives can be connected to the system at the same time

### 802.11 Wireless and Bluetooth
- **802.11** <- Technical standards which define the protocols for **Wireless Local Area Networks (WLANs)** AKA **WiFi**
	- Local Area Network (LAN)
	- High Speed
	- Internet Access
- Wireless components providing connectivity tend to be integrated into the motherboard
- Older laptops might use separate interface cards to provide the aforementioned connectivity
	- Examples of separate interface cards are:
		- **Mini PCI**
		- **Mini PCI Express**
	- Those with separate interface cards typically have connectors on them for the laptop antennas to connect to (often labelled **aux** and **main** on the card)
- Bluetooth:
	- Referred to as a **Personal Area Network (PAN)**
	- Short Range
	- Used to connect peripherals (e.g. external mouse, wireless headphones) and other nearby devices

##### WiFi Antennas
- 802.11 interfaces usually have a **main** connector and an **aux** connector
- Sometimes there's another antenna for Bluetooth as well
- Antenna wires often wrap around the laptop screen so they can reach as high as possible when the laptop screen is open

### Biometrics
- Sign in using **Something that you are**, i.e. fingerprint or face recognition
- May require additional config in the OS and typically requires specific hardware to be used
- Has become relatively secure due to the uniqueness of faces and fingerprints

### Near-Field Communication (NFC)
- Common on mobile phones and smart watches
	- i.e. payment method on your phone or wrist
- Short-distance networking
	- 4 cm or less
	- Used for data transfers or authentication
- Can be used for authentication without typing a password
- used in places such as:
	- Hospital workstations
	- Warehouses
	- Manufacturing

### Camera/Webcam
- Used for video capture
- Tend to to be built in to the laptop in the middle of the top part of the screen and often have a microphone on the left and right
	- Often basic, better quality and functionality usually requires the use of an external camera
- Usually include both audio and video
	- Using specialised drivers and software

### Microphone
- Typically built-in to the top of the laptop display
	- Useful for video calls
- Not good for non-casual use
	- Better to use an analog or USB microphone where higher quality is desired/needed
