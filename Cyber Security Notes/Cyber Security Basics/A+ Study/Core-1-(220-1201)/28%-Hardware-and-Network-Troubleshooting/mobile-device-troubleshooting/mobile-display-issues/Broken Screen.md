- **Caused by**:
	- Dropping device
	- Impact damage
- **Symptoms**:
	- Visible cracks on screen
	- Screen and digitiser still work if on outer glass is damaged
	- Lack of clarity or touch response indicates deeper damage to digitiser or display
- **Troubleshooting**:
	1. Determine extent of damage (outer glass vs deeper screen layers)
	2. If touch and display still work, only glass may need to be replaced
	3. If unresponsive, check digitiser for failure
- Glass typically integrated into display of mobile device
	- As such display may need to be replaced in order to replace the glass
- **Caution**:
	- Glass is sharp and may cut or embed itself into skin if screen is used while broken
		- Screen protectors can help prevent screen breaking as well as risk to self if continuing to use a broken screen
		- Use clear tape until glass is repaired/replaced
	- Backup mobile system prior to replacement
