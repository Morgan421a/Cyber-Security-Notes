- **Caused by**:
	- Low battery or unpowered stylus Bluetooth pairing issues
	- Faulty digitiser software or driver compatibility issues
	- Damaged or worn stylus
	- Worn out stylus tip
- **Symptoms**:
	- Stylus not detected by device
	- Intermittent or unresponsive performance
	- Inability to perform precise inputs
- **Troubleshooting**:
	1. If stylus is active (needs power), check stylus battery status and recharge if needed
	2. If stylus is Bluetooth, check connection and try re-pairing
	3. Check device screen for any physical damage
	4. Update software and stylus drivers
	5. Reset device (Phone/tablet, stylus too if possible)
	6. Check stylus and stylus tip for damage or wear, replace if necessary <- Tips can often be purchased separately
