- Cursor Drift = Random input or cursor moves without touching the device
	- Common on older screens
- **Caused by**:
	- Misaligned input zones
	- High touch sensitivity settings
	- Accidental wrist contact on trackpads
	- Bad display or a bad digitiser
	- Dirt such as grease or oils on display or trackpad
- **Troubleshooting**:
	1. Clean Trackpad or Display according to manufacturer's instructions
	2. Run a calibration tool to realign the touch screen (Digitisers)
	3. Adjust trackpad sensitivity settings to prevent accidental touches (Laptops)
	4. Enable settings to disable trackpad during typing (Laptops)
	5. - If issue persists, potentially means hardware issue such as needing a new display or trackpad

- Some older devices have a touch calibration app that require user input on certain points of the screen
	- Post calibration the system will adjust to new calibration parameters <- Should fix the drift
