- **Caused by**:
	- Interference from physical obstacles or electronic devices <- Can limit throughput
	- Incorrect SSID or password
	- Low signal strength due to distance from access point
	- Outdated or incompatible device drivers
	- Misconfigured software settings
- **Symptoms**:
	- Inconsistent or intermittent connection
	- Frequent Disconnections
	- Slow speeds or high latency
- **Troubleshooting**:
	1. Verify device connected to correct SSID and password
	2. Move closer to access point to improve signal strength
	3. Check for external interference e.g. other networks or devices using same frequency
	4. Inspect and update network card drivers
	5. Use external higher gain antenna to improve signal reception
	6. Forget the network and reconnect to reset any misconfigs
	7. Ensure airplane mode is disabled
	8. Access point Channel/Frequency config may need to be changed 
		- Areas with multiple access points can cause worse signal performance due to Radio Frequency (RF) Congestion
		- Sometimes adding more access points can make signal worse
- Stay within 30 - 50 metres of access point for optimal connectivity
- Use dual-band router to minimise interference
- Keep firmware on networking devices updated
