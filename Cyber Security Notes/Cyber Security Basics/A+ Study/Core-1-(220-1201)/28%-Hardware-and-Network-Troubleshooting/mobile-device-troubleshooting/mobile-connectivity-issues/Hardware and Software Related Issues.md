- **Hardware issues**:
	- Loose or disconnected antennas inside laptops
	- Faulty wireless network cards
	- External wireless network cards switched to "Off"
	- Damaged Bluetooth Components
- **Software Issues**:
	- Outdated device drivers
	- Incorrect wireless configs
	- Airplane mode switched on
- **Troubleshooting**:
	1. Ensure airplane mode is off
	2. Verify external wireless card is on
	3. Verify internal wireless card connections after hardware changes
	4. Update or reinstall drivers
	5. Check Wi-Fi/Bluetooth settings in OS
	6. Reset network settings to clear cached configs
	7. Carry out a power cycle by restarting the device
