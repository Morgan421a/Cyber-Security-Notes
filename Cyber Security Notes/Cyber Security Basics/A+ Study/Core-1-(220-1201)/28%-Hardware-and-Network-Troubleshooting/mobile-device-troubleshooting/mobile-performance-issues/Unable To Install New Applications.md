### Unable to Install New Applications
- **Symptoms**:
	- Error messages when attempting to install apps
	- App installs/downloads failing completely
	- Insufficient space warnings
- **Caused by**:
	- Insufficient storage
	- Incompatible software <- Outdated OS, app may need newer version
	- Security restrictions <- Mobile Device Management (MDM) policies preventing app installs, restrictions on unauthorised apps from app stores, user auth required
	- Corrupted files in cache
	- Poor network connection
- **Troubleshooting**:
	1. Ensure good network connectivity <-  Some apps need more bandwidth and a stronger connection for successful download
	2. Check Available space <- Check storage capacity and delete unnecessary data, transfer files to cloud storage or external drives to make more space
	3. Check for OS updates <- ensures system meets app requirements
	4. Clear App Store/Google Play store cache <- Removes corrupted, temporary files that might interfere with app installation
	5. Verify security settings and MDM policies by consulting IT department for approval or changes (If applicable), Check login credentials (if applicable) <- Logout and log back into account
