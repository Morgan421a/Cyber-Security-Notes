### Degraded Performance
- **Caused by**:
	- **Insufficient system resources**
		- Limited RAM and CPU processing power, too many background apps running simultaneously, accumulation of cached data from apps, low storage
	- **Outdated app or OS software**
		- Performance optimisation patches and bug fixes not installed
	- **Ageing hardware**
		- Reduced battery efficiency, slower storage drives, thermal throttling due to overheating
		- New apps might not support older hardware, resulting in poor performance or failure to run at all
	- **Hardware issues**
		- Bad RAM or damaged storage device may take longer to function, red/write from
- **Troubleshooting**:
	1.  Close unnecessary apps to free up RAM and CPU resources
	2. Clear device cache from settings menu
	3. Update OS and apps to ensure latest patches and bug fixes installed
	4. Check available storage and delete unnecessary files and apps
	5. Perform a factory reset if needed, **AFTER BACKING UP IMPORTANT DATA**
