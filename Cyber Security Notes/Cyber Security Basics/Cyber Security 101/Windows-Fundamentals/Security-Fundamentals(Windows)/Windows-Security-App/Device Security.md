##### **Device Security**
- Security which is built into the device
- **Core Isolation:**
	- Virtualisation-based security used to protect core parts of the device
		- **Memory Integrity** - Prevents attacks from inserting malicious code into high-security processes
		- **Security Processor** - Available in Personal Windows Devices (10 and onwards)
			- Device security processor, called the **Trusted Platform Module (TPM)**, is used to provide additional encryption to the device
	- **Should be left to default settings unless 100% confident**
