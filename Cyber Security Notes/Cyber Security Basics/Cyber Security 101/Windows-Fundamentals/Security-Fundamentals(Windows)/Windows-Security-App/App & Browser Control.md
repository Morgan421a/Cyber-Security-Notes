##### **App & Browser Control**
- Uses **Microsoft Defender SmartScreen** to protect against phishing or malware websites and apps, and the downloading of potentially malicious files
- **Check Apps and Files:**
	- Helps protect the device by checking for unrecognised apps and files from the web
	- Has 3 options:
		- **Block**
		- **Warn**
		- **Off**

- **Exploit Protection**
	- Built into Windows 10 (*and 11*) to help protect a device against attacks
	- **Should be left as default settings unless 100% confident
