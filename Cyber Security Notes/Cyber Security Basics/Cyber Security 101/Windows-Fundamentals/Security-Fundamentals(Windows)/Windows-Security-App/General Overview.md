#### **Windows Security**
- Available in settings
- Allows users to manage the tools used to protect their device and data
- 3 Status Icons, each with a different meaning:
	- **Green** - Device sufficiently protected, no recommended actions
	- **Yellow** - Safety recommendation that needs reviewing
	- **Red** - Warns that something needs immediate attention

- 4 areas of protection, as seen in previously the [[Windows Basics]] topic, to recap:
	- **Virus & Threat Protection**
	- **Firewall & Network Protection**
	- **App & Browser Control**
	- **Device Security**
