#### **Windows Editions**
- Current Windows version = Windows 11, Home or Pro
	- Pro is the same as Home except it has BitLocker Drive Encryption
- Current Server OS = Windows Server 2025
#### **Windows Updates**
- Updates typically released on **Patch Tuesday** <- 2nd Tuesday of each month
	- Ignored for critical updates/patches
- Updates can now only be postponed and not ignored forever <- done for the sake of security, ensuring devices have the latest updates/patches installed
