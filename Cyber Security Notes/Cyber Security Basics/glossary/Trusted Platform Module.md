- Trusted Platform Module (TPM)
	- A Technology designed to provide hardware-based, security-related functions. Such as providing additional encryption to a device
	- TPM Chip = A secure crypto-processor designed to carry out cryptographic operations.
		- Chip contains various physical security mechanisms to make it tamper-resistant
		- Malicious software unable to tamper with the security functions of the TPM
